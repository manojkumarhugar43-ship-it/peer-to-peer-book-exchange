# BookSwap — Peer-to-Peer Book Exchange Community

A modern React & TypeScript web application for local book lovers to lend, borrow, swap, and give away books in their community.

## Features

- **Home Page**: Hero with live exchange ticker, 4-step How-It-Works guide, exchange modality selector, and featured book listings.
- **Intent Selection Overlay**: Welcome goal picker (Sell Books, Buy & Borrow, Swap Books, Gift / Free).
- **Interactive Library Catalog**: Real-time multi-filter sidebar (by Exchange Type, Genre, Physical Condition, and Max Distance Radius 1–20 km), sorting (Newest, Distance, Popularity, Title), and Grid ⊞ / List ☰ view switch.
- **Book Details & Community Reviews**: Full edition specs, language, ISBN, condition assessment, loan/swap terms, owner profile with community trust rating, and reader review submission.
- **Interactive Nearby Map**: Neighborhood map with clickable book pins, radius radar controls, distance indicator, and quick-request previews.
- **Direct Messaging & Chat**: Real-time conversation threads with simulated replies, quick response suggestions, and book context badge.
- **List a Book (Add Book)**: Comprehensive listing flow with preset covers or image upload, exchange type selection, pricing, and lending duration.
- **User Profile & Bookshelf Management**: Personal book listings, active exchange proposal status updates (Pending, Accepted, Completed), and saved wishlist.
- **Authentication**: Seamless modal with quick demo login and account tabs.

## Tech Stack

- **Framework**: React 19, TypeScript
- **Styling**: Tailwind CSS v4 with custom serif typography & literary design system
- **Icons**: Lucide React
- **Build Tool**: Vite
